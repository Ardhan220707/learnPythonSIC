# 🐍 Learn Python - Samsung Innovation Campus (SIC)

Selamat datang di repositori dokumentasi pembelajaran **Python** saya selama mengikuti program **Samsung Innovation Campus (SIC)**. 

Repositori ini berfungsi sebagai catatan perjalanan, kuis, latihan pemrograman, hingga proyek-proyek kecil yang diselesaikan selama program berlangsung.

---

## 📌 Deskripsi Program
**Samsung Innovation Campus (SIC)** adalah program pelatihan teknologi yang berfokus pada pengembangan keterampilan digital, termasuk pemrograman (Coding & Programming), kecerdasan buatan (Artificial Intelligence), dan Internet of Things (IoT) untuk mempersiapkan talenta digital masa depan.

---
